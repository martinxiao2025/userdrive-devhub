# 录入检查清单

建任务前逐条自检，任何一条为「否」都先补全或提问。

| # | 检查项 | 判定标准 |
|---|---|---|
| 1 | 现象可复现 | 写清入口、步骤、实际结果与期望结果 |
| 2 | 范围可界定 | `writeScope` 能列出允许改动的目录或文件 |
| 3 | 完成可验收 | 至少一条可执行的验证方式（命令、断言、对比结果） |
| 4 | 无重复任务 | 已用 `queue_list` 与任务资源检索过同义任务 |
| 5 | 角色明确 | 已按「改代码 / 只判断 / 还说不清」选定角色 |
| 6 | 依赖已声明 | 前置任务写进 `dependsOn`，而不是描述文字 |
| 7 | 优先级有依据 | 有明确比较对象，不凭感觉给分 |

## 常见错误

- 标题即全部：没有现象与验收标准，执行角色只能猜。
- 一个任务多个目标：结果无法单独验收，审批时无法判断是否完成。
- 依赖写成文字：调度器看不到，会提前派发。
- 手改任务文件：来源与去重信息丢失，重复任务无法识别。
